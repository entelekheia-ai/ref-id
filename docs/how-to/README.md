# how-to/

Steps for one task you already have.

- [`identify-a-file.md`](identify-a-file.md) — give a file, or a heading inside it, the identifier every
  clone of its repository produces.
- [`mint-an-identifier.md`](mint-an-identifier.md) — name anything else somebody declared: pick the type,
  cut the fragment, add only the qualifiers that tell two records apart.
- [`write-a-resolver.md`](write-a-resolver.md) — turn an identifier back into the file it names, with the
  four resolution states.
- [`check-a-digest-before-storing.md`](check-a-digest-before-storing.md) — refuse an identifier whose
  digest does not recompute from its envelope, and read why it was refused.
